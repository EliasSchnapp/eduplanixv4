# Eduplanix Assets

Place the compiled Eduplanix frontend assets here.

Expected options:
- `manifest.json` from Vite build output (recommended).
- Or `eduplanix.js` + `eduplanix.css` as fallback.

Build suggestion (from repo root):
1. `npm install`
2. `npm run build`
3. Copy `client/dist/*` into this `assets/` directory.
